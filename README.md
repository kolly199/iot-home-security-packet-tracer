 IoT Home Security Network Using Cisco Packet Tracer

 Overview

This project documents my practical implementation of an IoT-based
home security network using Cisco Packet Tracer.

The lab focuses on connecting IoT security devices to a wireless
network, registering the devices with an IoT registration server,
and exploring IoT security functionality.

Objectives

- Connect IoT devices to a wireless network
- Connect the Home Siren to the Home Door
- Add IoT devices to the registration server
- Test communication between IoT devices and the server
- Explore IoT security device functionality
- Understand how IoT devices can be integrated into a security system

Tools and Technologies

- Cisco Packet Tracer
- IoT Devices
- Wireless Networking
- IoT Registration Server
- IoT Custom Cable
- Home Security Devices

Lab Implementation

 Step 1: Connect the Siren to the Door

The first step involved connecting the `Home_Siren` to the
`Home Doors` device using an IoT Custom Cable.

The connection was established between the DO interfaces of both
devices.

Result: 
The Home_Siren was successfully connected to the Home Doors device,
establishing the initial connection required for the IoT home security
system.
